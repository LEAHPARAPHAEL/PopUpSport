## How to launch the app ?

### Build the project (optional)

Perhaps you would like to create the .jar file by yourself. To do this : within a command prompt, once you reach the folder named *JANIN-Paul-MATHIOT-Raphael*, containing the src and bin folders and have Maven installed, type in the following command line :

    mvn clean package

The generated .jar will appear in the *target* folder. Choose the one **with** dependencies.

### Execution

The uploaded folder already contains the expected .jar file (named *JANIN-Paul-MATHIOT-Raphael.jar*).  Once you reach the folder named *JANIN-Paul-MATHIOT-Raphael*, please input the following command :

    java -jar JANIN-Paul-MATHIOT-Raphael.jar

Or launch it by double-clicking it !
